## 问题场景分析

### 场景1: 客户端说"调用失败了" → 服务端日志无任何记录

```
客户端: 调用 rds_ListInstances 失败
客户端日志: ToolError("UNKNOWN_TOOL") 或 ToolError("MISSING_CREDENTIALS")

服务端日志: （空白）← ToolError 没有 logger 记录！
```

### 场景2: 多个请求并发 → 日志无法区分

```
服务端日志:
  API请求失败: 实例不存在        ← 哪个请求？哪个用户？
  API请求失败: 权限不足          ← 哪个请求？哪个用户？
  意外的错误: ConnectionError    ← 哪个请求？哪个用户？
```

### 场景3: 请求成功 → 完全无日志

```
客户端: 调用 rds_ListInstances 成功
服务端日志: （空白）← 成功路径零日志！
```

## 日志覆盖对比总结

| 步骤 | 无 trace_id | 有 trace_id |
|------|-------------|-------------|
| 请求到达 call_tool | ❌ 无日志 | ✅ `[trace_id] call_tool: name=xxx` |
| 前缀路由 | ❌ 无日志 | ✅ `[trace_id] service_code=rds` |
| AK/SK 来源 | ❌ 无日志 | ✅ `[trace_id] AK/SK from=headers` |
| ToolError 类错误 | ❌ 无日志 | ✅ `[trace_id] error: UNKNOWN_TOOL` |
| 华为云 API 错误 | ✅ 有日志（无trace_id） | ✅ `[trace_id] API请求失败` |
| 网络异常 | ✅ 有日志（无trace_id） | ✅ `[trace_id] 意外的错误` |
| 调用成功 | ❌ 无日志 | ✅ `[trace_id] call_tool completed` |
| 华为云侧追踪 | ❌ 无法关联 | ✅ X-Trace-Id header 传到华为云 |
